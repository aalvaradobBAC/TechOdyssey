# M01 - IBM i y Visual Studio Code

## Objetivo

Comprender la plataforma IBM i y utilizar Visual Studio Code con Code for
IBM i para navegar objetos, editar fuentes y ejecutar una compilación guiada
antes de programar en RPG.

## Resultados de aprendizaje

- Diferenciar IBM Power, IBM i y AS/400.
- Reconocer bibliotecas, objetos, archivos fuente y miembros.
- Explicar la relación entre código fuente, compilación y objeto ejecutable.
- Configurar y utilizar Visual Studio Code con Code for IBM i.
- Navegar bibliotecas y miembros mediante Object Browser.
- Ejecutar una compilación guiada y localizar sus diagnósticos.

## Secciones

- M01-S01: Comprender la plataforma IBM i.
- M01-S02: Bibliotecas y objetos.
- M01-S03: Código fuente, miembros y compilación.
- M01-S04: Preparar Visual Studio Code.
- M01-S05: Navegar y editar con Code for IBM i.
- M01-S06: Primera compilación guiada.
- M01-S07: Evaluación y misión de cierre.

## Temas y subtemas

- Plataforma IBM i y arquitectura integrada.
- Bibliotecas, tipos de objeto y lista de bibliotecas.
- Archivos fuente, miembros, compilación y objetos ejecutables.
- Conexión remota y navegación con Code for IBM i.
- Edición controlada y revisión de cambios.
- Diagnósticos, corrección y confirmación del objeto generado.
- Seguridad y uso exclusivo de ambientes de entrenamiento.

## Prácticas guiadas

- Configurar una conexión de laboratorio a IBM i.
- Aplicar filtros en Object Browser.
- Localizar QRPGLESRC y abrir un miembro RPGLE.
- Agregar y guardar un comentario controlado.
- Compilar un miembro y revisar el objeto resultante.

## Retos

- Identificar biblioteca, archivo fuente, miembro y objeto generado.
- Leer diagnósticos y corregir problemas de compilación.
- Demostrar la diferencia entre fuente y programa *PGM.

## Criterios de finalización

- Completar las siete secciones M01-S01 a M01-S07.
- Acreditar el módulo una sola vez por cuenta.
- Conservar las unidades completadas y restaurarlas al iniciar sesión.
- Verificar que una cuenta diferente no herede el progreso.
