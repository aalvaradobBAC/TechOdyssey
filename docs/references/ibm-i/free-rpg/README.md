## Uso en la ruta RPG

Usar este documento como fuente técnica para preparar los módulos de RPG Free,
contrastar sintaxis y validar ejemplos. La especificación y el contenido
didáctico deben redactarse para los objetivos del aprendiz; el manual no
sustituye esos artefactos.

Cuando un módulo se apoye en esta referencia, registrar la edición y las páginas
consultadas en la sección de fuentes de ese módulo. Formato recomendado:

```text
<Autor o entidad>. <Título>. <Edición o versión>, p. <página(s)>.
```

No copiar capítulos ni convertir el manual completo a Markdown. Además de crear
una segunda copia difícil de mantener sincronizada, la reproducción puede
depender de los permisos de distribución. Si una sección específica resulta
difícil de consultar en PDF, crear apuntes breves y originales para el módulo
correspondiente, con referencias a las páginas y sujeto a los términos del
manual.
